# Cómo presentar NexaStock en tu portfolio

## Título recomendado

**NexaStock Fullstack — Plataforma SaaS de inventario y pedidos**

## Descripción breve

Aplicación full stack desarrollada con Java 21, Spring Boot, PostgreSQL, React y TypeScript para gestionar productos, clientes y pedidos. Incluye autenticación JWT, roles, dashboard, reglas de negocio, API REST documentada, Docker y tests.

## Enfoque profesional

Este proyecto está pensado para demostrar tres perfiles:

### Full Stack Developer

- Desarrollo de interfaz con React y TypeScript.
- Consumo de API REST.
- Gestión de sesión y token JWT.
- Formularios, tablas y navegación.
- Integración frontend-backend.

### Backend Developer

- Spring Boot 3.
- Spring Security.
- JPA/Hibernate.
- Validación de datos.
- Gestión de errores.
- Transacciones.
- PostgreSQL.
- API REST documentada.

### Software Engineer

- Arquitectura por capas.
- Separación de responsabilidades.
- Modelo de dominio.
- Documentación técnica.
- Dockerización.
- CI con GitHub Actions.
- Tests automatizados.

## Puntos fuertes para explicar en entrevista

1. El pedido no solo se guarda: valida stock, calcula importes y registra movimientos.
2. El frontend no está aislado: consume una API real protegida con JWT.
3. La base de datos no es un ejemplo plano: hay relaciones reales entre cliente, pedido, producto y movimientos.
4. El proyecto se puede levantar con Docker, por lo que es fácil de revisar.
5. La documentación ayuda a entender arquitectura, endpoints y decisiones técnicas.
