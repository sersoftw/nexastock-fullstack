# Guía rápida para subirlo a GitHub

## Opción recomendada desde la web de GitHub

1. Crea un repositorio nuevo llamado `nexastock-fullstack`.
2. No marques la opción de crear README, porque este proyecto ya lo incluye.
3. Entra en el repositorio vacío.
4. Pulsa **uploading an existing file**.
5. Arrastra el contenido completo de la carpeta `nexastock-fullstack`, no la carpeta comprimida.
6. Asegúrate de que se suben estas carpetas y archivos:
   - `backend/`
   - `frontend/`
   - `docs/`
   - `.github/`
   - `README.md`
   - `docker-compose.yml`
   - `.gitignore`
   - `Makefile`
7. Escribe un commit como:

```text
Initial fullstack portfolio project
```

8. Pulsa **Commit changes**.
